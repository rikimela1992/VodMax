# VodMax brand

| File | Use |
|---|---|
| `vodmax-wordmark-dark.svg` | The name, on dark backgrounds (apps, TV banner) |
| `vodmax-wordmark-light.svg` | The name, on light backgrounds (deeper gradient) |
| `vodmax-icon.svg` | App icon: the V on the dark rounded square; favicon |
| `vodmax-mark.svg` | The V alone, transparent |

- **Colours** — "Aurora" gradient from mint `#00F5A0` to azure `#00B8F5`
  (on light backgrounds `#00B377` → `#008FD1`); single accent in the
  interface `#00D6CA`. Backgrounds `#0B0C10` / `#1E1F29`. Red `#FF4D4F` only
  means recording or error.
- **Type** — [Sora](https://github.com/sora-xor/sora-font) (SIL Open Font
  License, `Sora-OFL.txt`): "Vod" Light 300, "Max" ExtraBold 800, tracking
  −2 %. In the files the text is converted to paths.
- **Small sizes** — below about 48 px use the V (`vodmax-icon.svg`), not the
  full name.
- Keep it away from the look of other video services: no play triangle, no
  red as the main colour.

**Use of the name and logo.** "VodMax" and these logos identify the official
project and are not covered by the AGPL code license. Modified versions and
forks must use their own name and logo; "based on VodMax" is fine. See the
README, section License.
