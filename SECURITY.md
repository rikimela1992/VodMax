# Security

If you find a vulnerability, **do not open a public issue**: use
[Report a vulnerability](https://github.com/silirim/VodMax/security/advisories/new)
(Security → Report a vulnerability). I answer as soon as possible.

Useful to include: the version (`vodmax-server -version`), how to reproduce
the problem, what it allows.

The credentials VodMax keeps (provider passwords and playlists, VPN, keys)
are encrypted on the server; never include them in a report.

---

## Sicurezza (italiano)

Se trovi una vulnerabilità **non aprire una issue pubblica**: usa
[Segnala una vulnerabilità](https://github.com/silirim/VodMax/security/advisories/new).
Utile includere: versione (`vodmax-server -version`), come riprodurre il
problema, cosa permette di fare. Le credenziali che VodMax conserva sono
cifrate sul server; non vanno mai incluse in una segnalazione.
